# Contributing to AWS Cloud Platform

Thank you for your interest in contributing! This document outlines the process for contributing to this project.

## Code of Conduct

This project adheres to the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## How to Contribute

### Reporting Issues

- Use the [GitHub issue tracker](https://github.com/brunalissa/aws-cloud-platform/issues)
- Provide a clear title and description
- Include steps to reproduce for bugs
- Include expected vs actual behavior

### Pull Requests

1. Fork the repository
2. Create a feature branch from `main`
3. Make your changes
4. Ensure all tests pass
5. Update documentation if needed
6. Submit a pull request using the provided template

### Commit Messages

This project uses [Conventional Commits](https://www.conventionalcommits.org/):

```
<type>: <description>

[optional body]

[optional footer]
```

Types:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation only
- `style`: Formatting, no code change
- `refactor`: Code restructuring
- `test`: Adding or updating tests
- `chore`: Maintenance tasks

Examples:
```
feat: add health check endpoint
fix: resolve database connection timeout
docs: update deployment instructions
```

### Development Setup

See the project [README](README.md) for local development instructions.

### Code Review

All submissions require review before merging. Maintainers will:
- Review within 48 hours
- Request changes if needed
- Approve and merge when ready

## Questions?

Open a [GitHub Discussion](https://github.com/brunalissa/aws-cloud-platform/discussions) for general questions.
